UsableFunctions

Get started Explore the API

Installation

From the Git repository

$ 
python -m pip install --upgrade git+https://github.com/Artemon0/UsableFunctions.git
Install from a wheel

Browse releases. If you downloaded a wheel, install it with this command.

python -m pip install ./path/to/downloaded.whl
